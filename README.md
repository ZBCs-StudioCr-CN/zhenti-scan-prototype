## 🏢 这是什么

这是一套面向**中小学培训机构**的「续费辅助系统 + 智能化运营方案」原型。

教培行业续费难，本质是**家长看不到效果**——老师讲得再好，没有数据支撑，家长续费就靠「信任」和「口才」。我们把这套痛点做成了可落地的系统：

| 环节 | 机构现状的痛点 | 我们提供的方案 |
|:---|:---|:---|
| 入学 | 靠老师经验判断学生水平 | **AI 入学测评**：10 秒生成基线报告，锁定漏洞清单与提分预期 |
| 过程 | 家长不知道孩子学了什么 | **阶段进步报告**：漏洞修复率 + 提分曲线，每周可量化 |
| 续费 | 老师靠嘴说，家长犹豫 | **续费证据链**：入学 vs 本次对比报告 + 剩余漏洞提分预估 |
| 沟通 | 老师话术水平参差不齐 | **话术体系**：基于报告数据自动生成，复制即用 |

## ✨ 核心能力

### 1. 专业学情诊断系统
- **试卷质量分析**：难度系数、区分度、信度、标准差、变异系数（对齐 K12 学情分析标准）
- **知识点掌握热力图**：按主题 × 模块展示本人掌握度 / 班级平均 / 与班差距
- **逐题得分明细**：题号、题型、考点、满分、得分、得分率、难度系数、区分度
- **跨学段漏洞溯源**：高中做错，一路追到初中/小学先修盲区

### 2. 续费证据链
- 入学测评 → 阶段测评 → 期末对比，自动生成进步曲线
- 漏洞修复率实时可见，提分预估有依据
- 续费不再靠老师口才，靠数据说话

### 3. 三角色报告体系
同一份试卷，自动生成三份各司其职的报告：

| 角色 | 报告内容 | 用途 |
|:---|:---|:---|
| 👨‍🏫 老师版 | 试卷质量 + 热力图 + 逐题表 + 溯源 | 教学诊断、备课依据 |
| 👨‍👩‍👧 家长版 | 分数定位 + 班级百分位 + 提分曲线 + 老师话术 | 让家长看见效果 |
| 🧑‍🎓 学生版 | 闯关式漏洞任务 + 成长激励 | 提升学习主动性 |

### 4. 智能化续费运营 SOP
我们交付的不只是工具，更是一套经过验证的续费流程：

```
① 入学建档 → ② 过程追踪 → ③ 续费触达 → ④ 续费转化
   基线报告       修复率周报      对比报告        家长会促成
```

### 5. 机构定制化能力
- 🏷️ **白标贴牌**：机构 Logo、品牌名全自定义，学生家长只认你的品牌
- 📚 **班级批量管理**：一键导入全班试卷，生成班级共性漏洞分布
- 📝 **自有题库**：机构可上传自编题，打造差异化教研
- 🔒 **数据私有化**：学生数据完全归属于机构，平台不截留

## 📚 知识点体系

基于 cn-math-taxonomy 与 K12 教材体系，已升级为 **3 大主题、16 模块、271 个课标考点**：

| 主题 | 模块数 | 考点数 | 高考分值 |
|:---|:---:|:---:|:---:|
| 📐 函数与导数 | 5 | 27 | ~60 分 |
| 📏 几何与代数 | 7 | 33 | ~57 分 |
| 📊 概率与统计 | 4 | 18 | ~33 分 |

每个考点关联：人教版教材定义、公式、标准解题套路、高频陷阱、最近考法。
漏洞可沿先修依赖链回溯到初中/小学底层盲区。

> 数学已上线，物理 / 化学 / 英语采用同款「漏洞扫描 + 续费证据」架构规划中。

## 🤝 机构合作

本项目开源的核心目的是**展示产品能力、寻求机构合作**。

### 合作模式

1. **白标私有化部署**：整套系统打上机构品牌，数据私有化
2. **续费运营陪跑**：提供续费 SOP、话术体系、家长会模板，陪机构把续费率做上去
3. **学科定制**：数学已上线，物理 / 化学 / 英语可按机构需求定制
4. **分成合作**：规模化复制后按续费分成

### 合作流程

```
预约演示 → 试点落地 → 定制运营 → 规模化复制
```
